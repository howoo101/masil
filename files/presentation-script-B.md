## Q&A (11장 · 질문 받기)

첫 문장으로 결론부터, 30초 안에. 모르는 건 “확인해 보겠습니다”라고 인정하기.

### 핵심 가치

**Q. 기억이 흐려진 어르신은 체크를 잊지 않나요?**  
→ 그래서 체크에만 기대지 않습니다. 걸음과 외출은 휴대폰 GPS가 기록하고, 체크는 보조입니다. ‘기억 안 나요’ 버튼을 따로 두었고, 기록이 없는 날을 ‘안 먹었다’로 세지 않습니다. 평소 잘 체크하던 분이 자주 잊기 시작하면 그 흐름 자체를 평소 2주와 비교해 봅니다. 진단받은 분은 대상이 아니고 보건소·치매안심센터로 이어 드립니다.

**Q. 안 드셨는데 ‘먹었어요’를 누르시면요?**  
→ 그래서 하루 체크로 판단하지 않고 걸음·활동 반경과 함께 평소 2주와 비교한 흐름을 봅니다. 알림도 진단이 아니라 ‘안부를 확인해 보세요’까지만 합니다.

**Q. 어르신은 왜 매일 체크하시나요?**  
→ 누르기만 하면 되고, 자녀에게 사진과 음성·영상 편지를 보낼 수 있는 곳이기 때문입니다. 실제로 매일 이어지는지는 4주 테스트에서 확인하겠습니다.

**Q. 복약 체크를 잘못 누르시면요?**  
→ 진단이나 처방 관리가 아니라 생활 기록입니다. ‘기억 안 나요’를 따로 두었고, 하루 기록보다 평소 2주와 비교한 흐름을 봅니다.

**Q. 위치 공유 앱과 무엇이 다른가요?**  
→ 실시간 위치를 보여 주지 않습니다. 집에서 얼마나 멀리, 얼마나 걸으셨는지만 기록하고, 평소와 달라진 점을 알려 줍니다.

**Q. 지자체 돌봄 서비스와 겹치지 않나요?**  
→ 겹치지 않고 이어 줍니다. 변화가 보이면 남양주보건소 방문건강관리와 시 돌봄 담당으로 바로 연결합니다.

### 실현 가능성

**Q. 어르신이 스마트 기기를 거부하시면요?**  
→ 실제로 어르신 두 분이 부정적이었습니다. 처음 설정은 자녀가 대신하고 어르신은 누르기만 하도록 바꾸겠지만, 거부감을 낮추는 건 아직 풀어야 할 숙제라 4주 테스트에서 가장 먼저 확인하겠습니다.

**Q. 걸음 수는 정확한가요?**  
→ 앱을 띄운 동안 GPS로 이동 거리를 재고, 보폭 65cm로 걸음을 추정합니다. 위치가 부정확하면 기록하지 않습니다. 만보기 수준의 정확도는 아닙니다.

**Q. 앱을 계속 켜 둬야 하나요?**  
→ 지금 웹 MVP는 화면에 띄운 동안만 기록합니다. 실제 서비스는 휴대폰 걸음 수 기능과 연결하는 게 다음 작업입니다.

**Q. 어르신이 스마트폰을 쓰실 수 있나요?**  
→ 체크는 누르기만 하면 됩니다. 실제 어르신 사용성은 4주 테스트에서 확인하겠습니다.

**Q. 보호자 휴대폰으로는 어떻게 보나요?**  
→ 지금은 같은 기기에서 함께 보거나, 어르신이 ‘가족에게 리포트 보내기’로 파일을 보내면 보호자가 열어 봅니다. 서버 연결은 다음 단계입니다.

**Q. 치매를 진단하나요?**  
→ 아닙니다. 평소와 달라진 점을 알려 주고, 안부 확인과 지역 기관 연결까지만 돕습니다.

### 검증

**Q. 실제 사용자 반응은요?**  
→ 40·50대 보호자들은 사용 의사를 보였고, 어르신이 쓰기 심플하다는 점과 사진 기록·공유를 좋게 봤습니다. 가장 많이 바란 건 약·식사·방문 장소의 개인별 맞춤 설정이었습니다.

**Q. 유료면 무엇이 달라지나요?**  
→ 체크와 리포트는 무료로 두고, 어르신별 맞춤 설정과 변화 알림을 유료로 검토합니다. 금액은 파일럿에서 정합니다.

**Q. 페르소나는 어떻게 구성했나요?**  
→ 부록 장을 보여 주세요. 보호자 40명(30·40·50대, 읍·면 부모님 26명, 혼자 사시는 부모님 24명), 11문항, 규칙과 코드를 공개했습니다.

**Q. AI 시뮬레이션은 검증이 아니지 않나요?**  
→ 맞습니다. 그래서 ‘팀 자체 점검’으로 표기했고 방향을 잡는 데만 썼습니다. 실제 검증은 10가정 4주 테스트입니다.

**Q. 성공은 어떻게 판단하나요?**  
→ 체크가 이어진 날의 비율, 그리고 알림 뒤 안부 전화나 기관 연결로 이어진 비율입니다.

### 지역·사업

**Q. 왜 남양주인가요?**  
→ 같은 시 안에서 수동면 40%, 다산동 14.2%로 고령화 차이가 커서 부모와 자녀가 따로 사는 가족이 많습니다.

**Q. 지역 기관과 연계됐나요?**  
→ 지금은 공개된 남양주보건소·시 돌봄 담당 번호로 안내하는 단계이고, 정식 연계는 검토 단계입니다.

**Q. 수익은?**  
→ 자녀 구독을 가정했고, 요금은 파일럿에서 정합니다.

### 개인정보

**Q. 개인정보는요?**  
→ 집 위치와 기록은 어르신 휴대폰에만 저장하고, 위치 기록은 어르신이 동의해야 켜집니다. 가족에게는 어르신이 고른 기록만 리포트로 보냅니다.
