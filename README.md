# 남양주 기억마실 · 테스트용 MVP

따로 사는 부모님의 식사와 마실(바깥나들이)을 평소 2주와 비교해 주간 리포트로 보여 주는 서비스의 시연 버전입니다. N:LOCAL 2026 남양주 해커톤 출품작입니다.

- 휴대폰: https://howoo101.github.io/masil/#phone
- PC(아이폰 프레임): https://howoo101.github.io/masil/#pc

## 시연 데이터

등장인물과 기록은 모두 예시입니다. 실제 결제나 전화는 하지 않습니다.

| 어르신 | 돌봄 가족 |
|---|---|
| 이정숙 (78, 수동면, 혼자 사심) | 김미경(딸, 주보호자) · 김민수(아들) |
| 박영호 (81, 화도읍, 부부) | 김미경(며느리, 주보호자) · 박준혁(아들) |
| 이정순 (74, 진접읍, 혼자 사심) | 김미경(조카, 주보호자) |

핵심 고리는 **어르신이 사진을 보내면 → 보호자가 한 번 눌러 답장하고 → 어르신 화면에 답장이 먼저 뜨는 것**입니다.

- 어르신이 쓰는 이유: 사진 한 장 보내면 자녀 답장이 꼭 와요.
- 보호자가 쓰는 이유: 매일 ‘오늘도 괜찮으세요’ 한 줄로 안심하고, 답장은 한 번 누르면 끝나요.

보호자 화면은 오늘 한 줄 안심과 답장 기다리는 사진이 맨 위에 있고, 그 아래 주간 리포트(판정 → 한눈에 보기 → 요일별 생활표 → 마실 기록 → 밥상 일기)는 평소와 다를 때만 알려 줍니다. 어르신이 밖에서 찍은 사진은 마실 기록, 밥때 찍은 사진은 식사 체크가 되고, 어르신 화면의 ‘이번 주 사진첩’으로 돌아옵니다. 시연 데이터의 사진은 그림으로 대신했습니다.

B안(팀원의 ‘마실’)에서 좋은 점을 가져와 합쳤습니다.

- **약 체크와 ‘기억 안 나요’**: 어르신 화면에서 식사 뒤 “약 드셨어요?”를 묻고, 식사·약 모두 ‘기억 안 나요’로 답할 수 있습니다. 보호자 화면의 오늘 카드, 생활표, 밥상 일기에 함께 보입니다.
- **건강 앱 걸음 연동**: 어르신 화면을 처음 켜면 알림 허용 창처럼 동의 창이 자동으로 뜨고, 허용하면 그다음부터 걸음이 저절로 들어옵니다(설정에서 켜고 끌 수 있음). 웹에서는 실제 건강 앱을 읽을 수 없어 시연 값으로 보여 주고, 설치형 앱으로 감쌀 때 `window.MasilHealth`(`requestAuthorization`, `getSteps`)를 넣어 주면 실제 걸음 수를 씁니다.
- **GPS 걷기 기록**: ‘걷기 기록 시작’을 누르면 화면을 켜 둔 동안 걸은 거리와 걸음 수(보폭 65cm 추정)를 기록합니다. 150m 넘게 움직이면 바깥나들이로 셉니다.
- **어르신별 맞춤 설정**: 보호자 화면의 ‘맞춤 설정’에서 약 먹는 때(아침·점심·저녁)와 요일별 마실 일정(복지관·병원 등)을 정합니다. 어르신 화면이 그날 약과 일정을 묻고, 리포트에 ‘정해 둔 일정 3번 중 2번’처럼 보입니다.
- **남양주 기관 연결**: 변화 알림 화면에서 요청 문구를 복사하고 남양주보건소 방문건강관리·시 돌봄 담당으로 연결합니다(시연에서는 전화하지 않음, 번호는 쓰기 전에 확인).

돌봄 가족은 어르신마다 따로입니다. 보호자 설정의 ‘보는 사람 (시연)’에서 김민수로 바꾸면 이정숙 님 리포트만 보입니다.

## 저장 방식

- 기록과 사진은 여는 브라우저에만 저장됩니다(localStorage, IndexedDB). 서버는 없습니다.
- 휴대폰과 PC는 서로 이어지지 않습니다. 각 기기에서 따로 시연해 주세요.
- 설정 → 테스트 초기화로 처음 상태로 되돌릴 수 있습니다.
